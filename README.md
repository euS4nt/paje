# Convite Digital de Casamento — Our Love Story

Projeto estático em HTML, CSS e JavaScript puro.

## Executar
Abra a pasta no VS Code e execute `index.html` com a extensão Live Server.

## Personalizar
Edite `js/config.js`: nomes, data, fotografias, história, endereços, dress code, presentes, WhatsApp e música.
Substitua as URLs das fotografias por imagens autorizadas do casal. Para confirmações, altere `rsvp.whatsapp` para o número completo com código do país e DDD, apenas números.

## Observações
- A confirmação abre uma mensagem pronta no WhatsApp; não salva dados em servidor.
- Os links de presentes são exemplos e devem ser substituídos por links reais.
- A música é opcional. Informe uma URL de áudio em `musicUrl`; o visitante precisa ativá-la.
- O mapa usa link externo do Google Maps.
- O layout mostra duas páginas por vez no desktop e uma página por vez no celular.
